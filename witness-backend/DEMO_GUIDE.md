## Short demonstration, after later UI integration

1. Create a clearly synthetic case and enter a fictional description. Save and freeze the original. Show that later clarifications have separate source/timestamp records.
2. Open Character Lab: all 45 attributes/seven groups, Unknown, subjective uncertainty and source quotes. Move/undo a slider. It must not generate until explicit Update Preview.
3. If live generation is separately authorized, submit once and show real job polling. Wait for a validated result; otherwise use a clearly labelled previously generated authorized fictional case. Never call synthetic fake-CLI tests live AI evidence.
4. Review a natural-language refinement prompt. Explain that a new child revision is a text-only interpretation, not guaranteed image-to-image identity preservation. Compare revisions and select a preferred version.
5. Sketch: draw an annotation, undo/redo, save a new editable revision; keep the original selectable. Enhance: apply a filter, wait for committed worker pixels, compare and save. These are local edits, not new AI generations.
6. Multi-view: show the AI-generated **2D** sheet and only explicitly reviewed front/left/right/three-quarter crops. Do not claim 3D reconstruction or verified likeness.
7. Generate a case report from persisted records. Download PDF, JSON and PNG; show exact testimony, sources/uncertainty, lineage and SHA-256. Unsaved browser drafts are excluded.
8. Refresh/reopen. Demonstrate restart persistence only after restarting the verified owned reference process on its isolated port. Never stop 8000 or 8001.

## Honest fallback and limitations

If a real image generation is slow, unauthenticated or quota-limited, say so and stop repeated submissions. Browse already authorized saved fictional results and perform actual local edits if available. If no saved collection exists, show source/schema and explicitly synthetic offline test results; do not imply the private historical collection was imported.

A composite is an illustrative hypothesis, not suspect identification, verified identity or proof of guilt. Unknown fields remain unknown even if pixels contain invented appearance. Recollection labels are not scientific probabilities. Sliders are prompt directions, not an anatomical mesh. Local sharpening cannot authenticate missing information. New generation requires network/tool access. The original worker watches a shared Codex output directory; keep unrelated image-generation sessions idle. Public multi-user deployment, forensic certification, identity locking, real 3D and image-to-image editing remain unverified.
